ℹ About The Project

Problem Statement

Landslides can cause serious damage to people, infrastructure and the environment. Early detection can help provide timely warnings.


Objective

To develop a monitoring system that analyzes environmental parameters and provides an early indication of landslide risk.


Future Scope

Real sensors, weather APIs, GPS/location data and a trained machine-learning model can be connected to this prototype in the future.
